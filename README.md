# ليلى كافيه ☕  
**الموقع الرسمي – Layla Cafe Website**

صفحة ويب واحدة (One Page) فخمة وبسيطة في نفس الوقت، معمولة خصيصًا لكافيه مصري شيك، شغالة 100% على الموبايل واللاب توب بدون أي تعقيد.


## المميزات اللي هتخليكي تقولي "ياااه"
- تصميم دافئ ومودرن ينفع أي كافيه في مصر  
- هيدر بطول الشاشة كامل مع صورة قهوة تجنن  
- منيو بشكل كروت أنيقة مع hover يرفع الكارت لفوق  
- متجاوبة تمامًا (Responsive) على كل الأجهزة  
- خط Cairo الجميل جدًا للعربي  
- ألوان هادية مريحة للعين (بيج – بني – ذهبي)  
- كود نظيف جدًا وسهل التعديل حتى لو أول مرة تفتحي HTML
